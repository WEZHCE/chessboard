# 棋艺对弈 · Gomoku & Go

一个简洁的网页棋类小游戏，支持：

- 五子棋：与电脑对弈，可选择简单、中等、困难三种难度。
- 围棋：与电脑对弈，支持落子、提子、停着和悔棋等基本操作。
- 战绩统计：分别统计五子棋和围棋的胜、负、和以及胜率。

## 在线体验

访问：[https://wezhce.github.io/chessboard/](https://wezhce.github.io/chessboard/)

## 重要提醒

网页中的战绩仅保存在当前设备、当前浏览器的本地存储（`localStorage`）中：

- 不会上传到服务器，也不会同步到 GitHub。
- 其他玩家看不到你的战绩。
- 清除浏览器缓存或网站数据、使用无痕模式、换浏览器或换设备后，战绩可能无法保留。
- 这些数据只是个人本地记录，不是全站共享排行榜。

如需清零战绩，可以点击页面上的“重置”按钮。

直接用浏览器打开 `index.html` 即可体验，也可以使用任意静态文件服务器运行项目。

