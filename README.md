# 棋艺对弈 · Board Games

一个纯前端棋类小游戏，支持井字棋、五子棋、围棋和中国象棋的人机对弈。

## 在线体验

[https://wezhce.github.io/chessboard/](https://wezhce.github.io/chessboard/)

## 当前功能

- 井字棋：简单随机模式，中等和困难模式使用 Minimax。
- 五子棋：15×15 棋盘，支持简单、中等、困难三档 AI。
- 围棋：支持 7、9、13 路棋盘，以及提子、禁入点、单步 Ko、停手、悔棋和计分。
- 中国象棋：支持基本走法、吃子、将帅判断、悔棋和三档 AI 难度。
- 统一战绩：分别统计四种棋类的胜、负、和与胜率。
- 棋面重复度：保存最近对局的最终棋面，并比较当前棋面与历史棋面的相似程度。

## 棋面重复度说明

当前指标采用启发式布局比较：

- 比较完整棋盘，包括双方棋子和棋子类型。
- 同一位置上的同一棋子是主要匹配依据。
- 同类型棋子距离较近时会获得少量相似度，用于反映整体布局接近程度。
- 棋子数量和类型数量不同会降低相似度。
- 结果是布局相似度参考值，不是棋力评估，也不是胜率。

## 数据与隐私提醒

战绩和棋面历史只保存在当前设备、当前浏览器的 `localStorage` 中：

- 不会上传到服务器，也不会同步到 GitHub。
- 其他玩家看不到你的本地战绩。
- 清除网站数据、使用无痕模式、更换浏览器或更换设备后，记录可能丢失。
- 这些记录是个人本地数据，不是全站共享排行榜。

点击页面上的“重置”按钮可以清除本地战绩和棋面历史。

## 项目结构

```text
app.js       应用初始化、战绩和公共交互
tic.js       井字棋逻辑与 AI
gomoku.js    五子棋逻辑与 AI
go.js        围棋逻辑与 AI
chess.js     中国象棋逻辑与 AI
```

## 本地运行

直接用浏览器打开 `index.html`，或使用任意静态文件服务器运行项目。
